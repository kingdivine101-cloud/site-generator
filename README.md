A faster drop-in for makefun-site 1.0.0: a single-pass index-based Markdown scanner with bulk-run escaping, templates compiled to JS via `new Function`, memoised slugify, and index-based front-matter parsing — pure JavaScript, no WebAssembly, no native addons, no prebuilt binaries. Grade-local: 3/3 practice cases byte-identical to the baseline.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
